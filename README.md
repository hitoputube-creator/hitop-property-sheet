# 하이탑 매물장 자동생성 시스템 (React + Vite)

토지/상가/공장창고 매물을 입력하고 localStorage에 저장한 뒤,
실무용 인쇄 레이아웃으로 **비교 매물장(A4 1장 최대 3개)** 또는 **개별 매물장(A4 1장 1개 상세)** 을 생성하는 앱입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 사용 순서

1. 입력
2. 저장
3. 목록 확인
4. 비교/개별 매물장 선택
5. 인쇄

## 주요 기능

- 거래유형(매매/임대/매매+임대) 선택 및 가격 항목 동적 표시
- 면적 평/㎡ 동시 입력 및 자동 계산 (`1평 = 3.3058㎡`)
- 도로접면/진입도로 별도 입력칸 제거, 비고/AI 요약으로 통합
- 저장 시 즉시 목록 반영 + 방금 저장한 매물 자동 선택 + 개별 매물장 미리보기 전환
- 저장 목록에 체크박스, 매물유형, 거래유형, 소재지, 주요 가격, 면적, 수정/삭제 표시
- 비교 매물장(선택 1~3개, 동일 유형) / 개별 매물장(선택 1개) 조건 검증
- 데이터는 브라우저 `localStorage(propertyListingsV1)`에 저장

## 기술 메모

- 외부 API/서버/로그인 없이 프론트엔드 단독 동작
- React + Vite 구조 유지
