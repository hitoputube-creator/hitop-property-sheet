# 하이탑 매물장 자동생성 시스템 (React + Vite)

토지/상가/공장창고 매물을 입력하고 localStorage에 저장한 뒤,
실무용 인쇄 레이아웃으로 **비교 매물장(A4 1장 최대 3개)** 또는 **개별 매물장(A4 1장 1개 상세)** 을 생성하는 앱입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 변경된 핵심 사용법

### 사용 순서

1. 입력
2. 저장
3. 목록 확인
4. 비교/개별 매물장 선택
5. 인쇄


- 모든 매물 유형에 `거래유형(매매/임대/매매+임대)` 선택 버튼이 추가되었습니다.
- 거래유형에 따라 가격 입력 항목이 자동으로 노출됩니다.
  - 매매: 매매가격, 평당가
  - 임대: 보증금, 월세, 관리비
  - 매매+임대: 위 항목 모두
- 면적 입력은 평/㎡ 동시 입력 및 자동 연동입니다.
  - 기준: `1평 = 3.3058㎡`
  - 평을 입력하면 ㎡ 자동 계산
  - ㎡를 입력하면 평 자동 계산
- 도로접면/진입도로/도로 설명은 별도 입력 칸 없이 `비고` 또는 `AI 매물 분석 요약`에 작성합니다.
- 매물 저장 시 자동으로 방금 저장한 매물이 선택되며, 출력 미리보기는 개별 매물장으로 전환됩니다.
- 저장된 매물이 없으면 미리보기에 안내 문구가 표시됩니다.

## 출력 규칙

- 면적은 비교/개별 양식 모두 `100.00평 / 330.58㎡` 형식으로 출력됩니다.
- 거래유형별로 가격 정보가 출력됩니다.
  - 매매: 매매가격/평당가 중심
  - 임대: 보증금/월세/관리비 중심
  - 매매+임대: 매매와 임대 항목 모두
- 도로접면은 별도 항목 출력 없이 비고/AI 요약에 포함된 내용만 표시됩니다.

## 기술 메모

- 외부 API/서버/로그인 없이 프론트엔드 단독 동작
- 데이터는 브라우저 `localStorage(propertyListingsV1)`에 보관
- React + Vite 구조 유지
