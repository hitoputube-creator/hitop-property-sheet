# 매물장 자동생성 웹앱 (React + Vite)

토지, 상가, 공장창고 매물을 입력하고 localStorage에 저장한 뒤,
비교 매물장(페이지당 최대 3개) 또는 개별 매물장(AI 요약 포함)으로 출력/인쇄할 수 있는 앱입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 표시된 로컬 주소(예: `http://localhost:5173`)로 접속하세요.

## 주요 기능

- 매물 유형 3종(토지/상가/공장창고)별 동적 입력폼
- 대표사진 base64 저장(localStorage)
- 저장 매물 목록 + 체크 선택
- 비교 매물장 생성(한 페이지 최대 3개)
- 개별 매물장 생성(한 페이지 1개 + AI 매물 분석 요약)
- 인쇄 시 입력폼/목록/버튼 숨김, 출력물만 노출(A4 세로 최적화)
