# 하이탑 매물장 자동생성 시스템 (React + Vite)

토지/상가/공장창고 매물을 입력하고 localStorage에 저장한 뒤,
실무용 인쇄 레이아웃으로 **비교 매물장(A4 1장 최대 3개)** 또는 **개별 매물장(A4 1장 1개 상세)** 을 생성하는 앱입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 표시된 로컬 주소(예: `http://localhost:5173`)로 접속하세요.

## 현재 기능

- 매물 유형 3종(토지/상가/공장창고)별 동적 입력폼
- 대표사진 base64 저장(localStorage)
- 저장 매물 목록에서 선택/수정/삭제
- 비교 매물장
  - 같은 유형 매물만 선택 가능
  - 최대 3개 선택 가능
  - A4 세로 1장에 네이비/화이트 인쇄형 구성
- 개별 매물장
  - 매물 1개만 선택 가능
  - 상단 제목 + 대형 대표사진 + 기본정보표 + AI 요약 + 비고
- 선택 조건 불일치 시 화면 안내 문구 표시
- 인쇄 시 입력폼/목록/버튼 숨김, 출력 양식만 A4 최적화

## 사용 흐름

1. 좌측 입력폼에서 매물 유형을 선택하고 항목을 입력 후 저장합니다.
2. 하단 저장 목록에서 매물을 선택합니다.
3. 우측 미리보기에서 `비교 매물장` 또는 `개별 매물장` 모드를 고릅니다.
4. 조건이 맞으면 인쇄 버튼으로 PDF 저장 또는 출력합니다.

## 기술 메모

- 외부 API/서버/로그인 없이 프론트엔드 단독 동작
- 데이터는 브라우저 `localStorage(propertyListingsV1)`에 보관
- Vercel 정적 배포에 그대로 사용 가능
